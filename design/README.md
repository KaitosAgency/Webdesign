# Design

Chaque essai vit dans son propre sous-dossier.

## Projets actifs

- **`portfolio-demo/`** — Portfolio one-page React + Vite + Tailwind + shadcn/ui (FR). Voir [`portfolio-demo/README.md`](portfolio-demo/README.md).

## Créer un nouveau projet

1. Créer un dossier `design/<nom-projet>/`.
2. Documenter stack et commandes dans un `README.md` local.
3. Ajouter une entrée dans [`docs/MEMORY.md`](../docs/MEMORY.md) et dans ce fichier.
4. Respecter [`docs/CONVENTIONS.md`](../docs/CONVENTIONS.md) pour tout projet React.
